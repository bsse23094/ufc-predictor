# Infrastructure

Milestone 1 provides the local Docker Compose topology at the repository root. Environment-specific deployment, monitoring, dashboards, alerts, and infrastructure-as-code are deferred to their architecture gates and must not be improvised before provider, budget, and residency decisions are approved.

See [Deployment architecture](../docs/architecture/DEPLOYMENT_ARCHITECTURE.md) and [Observability plan](../docs/architecture/OBSERVABILITY_PLAN.md).
