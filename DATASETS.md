# Datasets

No production, scraped, golden, ranking, odds, scorecard, or pre-UFC dataset is included in this repository.

The intended data zones are documented in [data/README.md](data/README.md). A dataset may be published only after source-policy approval, immutable raw preservation, row accounting, identity resolution, temporal validation, and a versioned manifest. The golden modelling dataset remains comparison-only unless a later audit and ADR explicitly approve a different role.

For the governing design, see [Data architecture](docs/architecture/DATA_ARCHITECTURE.md) and [Data source audit](docs/architecture/DATA_SOURCE_AUDIT.md).
